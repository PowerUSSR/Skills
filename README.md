# Skills

Плагин прокачки персонажа для Paper/Spigot 1.20 на сервере **VortexiaPolit** — система игровых навыков (воровство, эндер-сундук, скрытность и др.), доступная через GUI-меню.

## Команды

| Команда | Описание |
|---|---|
| `/skills` | Открыть меню навыков |
| `/rob <ник>` | Ограбить игрока (навык воровства) |

Полный список команд и описание навыков — см. `Skills-commands.txt` на боевом сервере.

## Сборка

Скомпилируйте `src/` под classpath Paper API 1.20.

## Совместимость

- Minecraft **1.20.1**
- Ядро сервера: **Mohist 1.20.1** (плагин используется на сервере VortexiaPolit)
- Написан на Bukkit/Spigot API, поэтому может работать и на Paper/Spigot 1.20.x
